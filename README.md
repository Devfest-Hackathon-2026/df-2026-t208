# なぞまちワールド（NAZOMACHI WORLD）

**「地球の全部が、事件現場になる。」**

DevFest GDGoC Japan Hackathon 2026 / チーム みらいクラフト（DF-2026-T208・大阪会場）
カテゴリ： Entertainment（主）× Tourism（副）

**公開URL: https://nazomachi-world-a3598.web.app**（Firebase Hosting、Regional Day 2026-11-14 まで公開維持）

## これは何か

行き先を決めると、**その街専用のミステリー（事件）がその場で生成される**探索ゲームです。

街歩き・観光コンテンツは「作るコスト」が高いため有名観光地にしか存在せず、ほとんどの街は素通りされ、観光は有名地に一極集中します（オーバーツーリズム）。なぞまちワールドは、事件の制作コストを生成エンジンでゼロにすることで、どの街にも「行く理由」と物語を届けます。

## 遊び方（画面の流れ）

1. **ホーム**：行き先の街を入力すると、その街専用の事件が生成される（事件生成エンジン）。監修済みの事件ファイル（大阪・梅田／京都・祇園／東京・浅草）から選ぶこともできる。語り口（探偵もの／学園もの／ホラー風）で導入の雰囲気が変わる
2. **事件発生**：導入文、舞台になる実在スポット5件、容疑者3名が提示される
3. **捜査**：Google Maps 埋め込みで実際の街並みを見ながらスポットを巡り、手がかりを集める
4. **AIゲームマスター**：詰まったら段階ヒント（Lv.1〜3）で誰でも最後まで到達できる
5. **推理→解決編**：犯人とトリックの両方を推理。正解すると真相と一緒に「その街の本当の話」（実在の歴史・名物）が明かされる。結果はリンクでシェアでき、友だちも同じ事件に挑戦できる

UI全体・監修3事件・生成エンジンのすべてが**日本語／英語対応**（画面上のJP/EN切替、ブラウザ言語が英語なら初回から英語）。

## 事件生成エンジン（本プロダクトの核）

任意の行き先（市区町村名など）を入力すると、物語の型6系統（職人の設計図／祭りの宝物／時計台の制御データ／老舗のレシピ／橋の原版／商店街の原画）×実在スポットの型10種（駅前・商店街・社寺・橋・市場・公園・資料館・史跡・港・展望）×容疑者・トリック・手がかりの連鎖を、行き先の名前をシードにして**決定的に**組み立てます。同じ行き先からは同じ事件が生まれるため、URL共有や再訪でもブレません。生成は端末内で完結し、待ち時間もAPIコストもゼロです。生成された事件は監修済み事件と同等に、詳細・捜査・推理・解決編の全フローで遊べます。

## 技術構成と「なぜその技術か／捨てた代替案」（Own the Why）

| 技術・判断 | 役割／なぜこれでないとダメか | 捨てた代替案と理由 |
|---|---|---|
| Firebase Hosting（Spark・無料枠） | Google実行基盤の要件を満たす。バックエンドなしの構成には静的ホスティングで十分で、運用コストゼロ | Cloud Run バックエンド → 課金アカウント必須で、現アーキテクチャでは不要 |
| Google Maps 埋め込み（キー不要） | 事件の舞台である実際の街並みの表示。APIキーなしで表示でき、キー漏洩・課金リスクがない | Maps JavaScript API（キー発行） → 表示要件に対して過剰 |
| 端末内・決定的生成エンジン | 待ち時間ゼロ、APIコストゼロ、同じ行き先＝同じ事件の再現性でシェアが成立 | 完全リアルタイムAPI生成 → 30秒〜1分以上の待ち時間と品質の未検証リスク（設計批評ループで指摘を受け切替） |
| Gemini（設計フェーズ） | 監修シナリオの設計パートナー（梅田編シナリオ採用）、デザイン批評ループでの客観批評 | 人間だけの執筆 → 街の数だけコストがかかり、本プロダクトの核（制作コストゼロ）と矛盾 |
| まちモード（GPSチェックイン）を今回は実装しない | 屋内審査会場でのGPS実機検証リスクが高く、核である生成と推理体験の磨き込みを優先 | 両モード同時実装 → 二兎追いで共倒れのリスク |

本番構想：Cloud Run に生成バックエンドを置き（APIキーはサーバー側のみ）、Places API で実在スポットの裏付けを取り、Gemini のオンデマンド生成＋キャッシュで世界中の街に対応。Firestore で事件データとシェアを管理し、まちモード（GPS）を追加する。

## 動かし方

ビルド不要・依存なしの静的サイトです。

- **そのまま開く**：`index.html` をブラウザで開く（地図表示にはインターネット接続が必要）
- **ローカルサーバー**：このフォルダで `python3 -m http.server 8000` → http://localhost:8000
- **Firebase Hosting へデプロイ**：`firebase deploy --only hosting`（`firebase.json` の `public: "."`）
